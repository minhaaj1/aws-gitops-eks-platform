# AWS GitOps EKS DevOps Platform

An end-to-end DevOps project demonstrating:

- Linux
- Git & GitHub
- Docker
- Jenkins CI/CD
- Terraform
- AWS EKS
- Kubernetes
- ArgoCD
- Prometheus
- Grafana

## Architecture

Application source code is stored in GitHub and delivered through an automated CI/CD and GitOps workflow.
